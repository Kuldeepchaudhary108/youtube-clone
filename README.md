# 📺 YouTube Clone

A fully responsive and feature-rich YouTube Clone web application that replicates the core functionality of YouTube. Built using modern web technologies, it allows users to search, watch, and explore videos seamlessly.

## 🚀 Features

- 🎥 **Video Streaming** – Watch videos fetched in real-time from the YouTube Data API.
- 🔍 **Search Functionality** – Users can search videos by title, keyword, or channel name.
- 📊 **Video Stats** – View like count, view count, and publish date for every video.
- 🧠 **Smart Recommendations** – Suggests related videos based on current selection.
- 🔗 **Dynamic Routing** – Each video has a unique, shareable URL.
- 📱 **Responsive Design** – Works flawlessly on mobile, tablet, and desktop screens.
- ⚡ **Optimized Loading** – Lazy loading and performance-focused design.

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Routing**: React Router DOM
- **API**: YouTube Data API v3
- **State Management**: useState, useEffect (React Hooks)
- **Deployment**: Vercel / Netlify / GitHub Pages
